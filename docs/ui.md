# UI principles

The administration interface is an operational developer tool, not a marketing dashboard.

- Dense tables and lists instead of oversized metric cards.
- Health is communicated with text and restrained red/green indicators, never color alone.
- Fine dividers, 6–8 px radii, and minimal shadows.
- No gradients, glassmorphism, glowing containers, decorative charts, or animated clutter.
- Server selection and tool inspection remain visible together on wide screens.
- Dark and light themes share the same hierarchy and spacing.
- The browser loads three embedded static files and no third-party scripts, fonts, or analytics.
